02 / 傅里叶分解TRANSFORM
128262144

支持 128–262144 点。FFT 使用 2 的整数次幂档位；输入的点数会向上取到可用档位。自定义范围内至少需包含一个档位。增加采样点能减小采样误差；恢复细节还需增加旋转向量数量。

傅里叶成分保留率—

按旋转向量长度的平方加权计算。数值越高，通常保留的细节越多；不表示图形相似度，也不是向量数量比例。

曲线偏差 —

偏差越小，重建的采样点越接近原曲线。按统一缩放后的坐标计算均方根误差（RMS），单位不是屏幕像素。

A LITTLE MATH, A LOT OF POSSIBILITY

每一条曲线，都是许多圆的合奏。

把平面点写成复数 z = x + iy，等弧长采样，再用 FFT 计算离散傅里叶系数。每个系数是一根旋转向量：长度是振幅，角速度由频率决定，初始角度是相位。首尾相接后，最后一根向量的端点就画出了原曲线。

  1. 选择示例，或手绘 / 导入自己的曲线。
  2. 减少旋转向量观察轮廓简化，增加旋转向量提高还原度。
  3. 用频谱查看频率成分；用 x / y 信号理解两个坐标随时间的变化。
  4. 拖动周期滑块逐帧观察；滚轮缩放，按住 Shift 拖动平移。
  5. 导出图片、矢量曲线、系数或动画；保存 JSON 项目下次继续。

FFT 对有限采样点精确。点之间的还原仍受采样密度影响；转角和笔画跳转处可能出现振铃。隐藏连接线只是抬笔显示，不会从信号里删除跳转。

项目自动保存在当前浏览器中。所有图形与文件在本机处理；清除浏览器数据会删除自动保存。
