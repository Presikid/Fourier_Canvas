# Fourier Canvas · 傅里叶绘图工作台

项目主仓库：[Presikid/Fourier_Canvas](https://github.com/Presikid/Fourier_Canvas)。

一个纯静态、中文界面的傅里叶绘图工具。把曲线分解成旋转向量，再由向量端点重新画出图形。全部运算在浏览器本机完成，没有后端、账号、统计脚本或第三方运行时依赖。

## 功能

- 手绘：鼠标或触摸、多笔画、撤销/重做、单笔闭合、隐藏移动段。
- 示例库：附图描绘的“图1 · 笑脸”及“图2 · 精细线稿”（554 笔画）预设、心形、蝴蝶、星星、花朵、三叶结、李萨如、方形、螺旋。
- 参数曲线：玫瑰线、利萨如曲线、内旋轮线，整数参数可调。
- 导入：SVG 几何、CSV 坐标、JSON 项目；支持拖放。
- 文字：通过本机字体绘制和像素边界追踪，提取字符外轮廓与内部孔洞。
- 计算：复数 FFT、128–262144 个等弧长采样点、采样预设／直接输入／可自定义最小值和最大值的滑动条、振幅排序或低频优先、自动选择旋转向量（保留 99% 成分）、傅里叶成分保留率与曲线偏差。
- 动画：播放/暂停、重新开始、正向/反向、0.1–4 倍速度、循环与单次播放、时间滑块。
- 分析：振幅频谱、x(t)/y(t) 信号、前 100 项系数表和完整系数 CSV。
- 画面：旋转圆、向量、原曲线、完整重建、网格、镜头跟随、缩放/平移、全屏。
- 风格：明暗主题、线宽、颜色、圆透明度、柔光、完整轨迹、短尾迹、时间渐变。
- 导出：独立“导出”标签页，可继续编辑的 JSON 项目、当前画面 PNG、完整重建 SVG、原始笔画 SVG、系数 CSV、源坐标 CSV、一周期 WebM 动画。
- 项目：浏览器自动保存、JSON 保存与恢复。
- 适配：桌面三栏工作台、手机纵向布局；键盘焦点与减少动态效果偏好。

## 立即使用

推荐打开 GitHub Pages 网站，或用静态服务器运行源码（例如 `python -m http.server 8080`）。推荐新版 Chrome、Edge 或 Firefox。WebM 录制取决于浏览器的 MediaRecorder 与编码器支持；不支持时会禁用录制。

浏览器从 `file://` 打开时，后台线程可能被浏览器阻止；请通过 HTTP/HTTPS 使用。保存 JSON 项目可以单独保留作品。

将本目录**内部的全部内容**放在仓库根目录，包括 `.github/workflows/pages.yml`，默认分支使用 `main`。

仓库设置中进入 **Settings → Pages → Build and deployment → Source → GitHub Actions**。推送 `main` 后，工作流执行 JavaScript 语法检查和自动测试，再部署运行文件及预设轮廓资源。无需 npm 安装或打包。

所有资源使用相对路径，支持 `https://用户名.github.io/仓库名/`，也支持自定义域名。若默认分支不是 `main`，相应修改工作流触发分支。

## 使用方法

1. 选择示例，或进入手绘，先清空画布再画自己的图。
2. 绘制完成后点击“分解曲线”。减少旋转向量数量可观察平滑的近似轮廓。
3. 在频谱、信号和系数表之间切换；拖动周期位置观察指定时刻。
4. 滚轮缩放；按住 Shift 拖动画布平移；“适应”恢复视角。
5. 进入“导出”标签页，导出 JSON 项目，下次从导入页加载；也可导出图片、曲线和动画。

快捷键：空格播放/暂停，R 重新开始，D 切换绘制模式，F 全屏，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。输入框获得焦点时不触发这些快捷键。

顶部“导出项目”和导出标签页中的“导出项目（JSON）”均会下载可继续编辑的完整项目。原始 SVG 与坐标 CSV 可重新导入；系数 CSV 是分析数据，不能当作坐标 CSV 导入。

PNG 是当前画面；SVG 是完整重建曲线，透明背景，不包含旋转圆和网格。系数 CSV 包含所有频率及其是否保留。坐标 CSV 导出源笔画，空行分隔；可再次导入。

录制会从零开始正向绘制一周期，期间锁定设置。请将页面保持在前台；后台页面的浏览器节流可能延长录制时间。点击录制按钮可提前停止并保存。

## 图1笑脸预设

根据用户提供的卡通图片手工描绘头发、笑眼、露齿嘴和脸部轮廓，保留 48 个独立笔画，省略背景和实心色块。它是线条还原，不是彩色照片复刻；同样经过 FFT 分解及旋转向量重建。默认采用 4096 个采样点、700 根向量、隐藏移动段和粉色轨迹；为便于看清图形，选中时关闭圆环与向量图层，可手动打开。SVG 源文件位于 `assets/smile-reference.svg`。

## 图2精细线稿预设

从用户上传的 512×512 GIF（单帧）提取像素边缘，保留顶部和底部文字、头发、眼睛、花饰、衣服与背景轮廓。共 554 个独立笔画、28819 个源坐标点。默认 131072 个采样点、全部 131072 根向量，隐藏笔画间移动；选中后暂停在完整绘制结果，点击播放可观察过程。关闭圆环、向量、网格和柔光，并使用细线。

这是原图的详细线稿，保留可提取的轮廓与明暗边界；不包含彩色填充，不能声称与彩色原图逐像素一致。所有笔画经 FFT 与逆变换重建。原图对照保存在 `assets/detail-reference.svg`，提取轮廓保存在 `assets/detail-contours.svg`。完整源点可导出为 JSON、SVG 或 CSV。离线提取脚本 `scripts/trace-reference.py` 可从已保存的原图重新生成坐标与轮廓，需 Python、Pillow、NumPy、SciPy；这些仅用于开发，网站运行不依赖它们。

## 采样数量与滑动范围

提供 128、256、512、1024、2048、4096、8192、16384、32768、65536、131072、262144 共 12 档。可在“输入采样点数”中填写数值，也可拖动滑动条。当前 FFT 使用 2 的整数次幂，因此输入 5000 会使用 8192 点；如果超过自定义范围的最高可用档位，则使用该最高档位。

“滑动条最小值”和“滑动条最大值”决定可选范围，同时约束下拉预设与直接输入。范围内至少要有一个可用档位。例如最小值 1000、最大值 10000，实际档位为 1024–8192；界面显示实际可用端点。无效范围会提示并保留此前设置。范围与采样数量随 JSON 项目保存，旧项目自动使用默认范围。

高采样数增加计算精度，不会创造原始轮廓里不存在的细节；旋转向量数量过少时，细节仍会被舍弃。滑动调节延迟 160 毫秒重新计算，放开滑动条后立即计算。

为控制高采样数下的预览开销，一般画布约绘制 6000 个均匀分布的轨迹点；超过 20000 个源坐标点的复杂图使用约 24000 个预览点，额外保留抬笔切换处的点。旋转圆和向量图层最多显示前 800 项，其余向量的合成以虚线接到完整轨迹笔尖；界面会注明。超过 2000 根向量时，动画笔尖在完整重建采样点之间插值。FFT、完整重建和 SVG 导出继续使用全部选择的数据；预览简化不删除计算或导出中的采样点。

## 大采样计算与取消

采样、FFT、系数排序、完整重建、统计、频谱分箱及大 SVG/CSV 导出均在 Web Worker 中执行，避免 131072/262144 点的同步任务阻塞页面主线程。计算时显示状态并提供“取消计算”。切换设置会终止尚未完成的任务，过时结果不会覆盖新图形。Worker 缓存同一源图的排序结果；界面只接收可转移的数值缓冲区、100 个频谱柱及100行系数，不在每次刷新频谱时重新排序几十万个对象。

后台线程失败会给出错误提示，不会退回高采样量的主线程计算。未提供 Worker 的环境仅允许不超过32768点的兼容计算。

## 数学约定

把第 j 个点写成 `z_j = x_j + i y_j`，FFT 使用负号计算：

`c_k = (1/N) Σ_j z_j exp(-2π i k j/N)`

重建：`z(t) = Σ_k c_k exp(2π i k t)`。正频率和负频率表示相反的旋转方向，零频率是曲线的平均位置。画布的 y 坐标向下。

界面中的“傅里叶成分保留率”是保留向量的长度平方之和，占全部向量长度平方之和的比例；不是向量数量比例，也不是图形相似度。“自动选择向量”以该比例达到 99% 为目标，按当前选择顺序决定向量数量。“曲线偏差”表示重建采样点相对于原始采样点的均方根误差（RMS），越小越接近。界面同时提供这些解释。

源图形按包围盒居中，并按最长边归一化到 500 单位。RMS 误差使用归一化后的坐标，按 Parseval 等式计算截去的能量。频谱为了适应画布，最多显示 100 个频段，每个频段取最大振幅，不是累加能量。

FFT 对离散采样点精确；完整保留谐波时，重建在采样时刻与输入一致。采样点之间的细节仍受采样数影响；锐角和笔画之间的移动可能产生振铃。

每笔末尾到下一笔开头的移动段参与采样与变换。“隐藏笔画间的连接线”只控制抬笔显示。开放曲线的末尾到开头也是隐藏的移动段，保持周期信号完整。文字轮廓较多时，移动段和采样密度会影响效果。

## 导入格式与限制

CSV 例子：

```csv
x,y
0,0
100,0
100,100

200,0
250,50
```

SVG 支持 path（包括独立子路径）、circle、ellipse、line、polyline、polygon、rect，以及分组 transform 与根 viewBox。只读取几何，不模拟填充、裁剪、CSS、隐藏状态、嵌套 SVG 的视口或文本。百分比几何值不支持；文字、图片和 use 引用需先转为路径。导入文件的脚本、事件、链接及外部资源不会放进页面。

输入限制：单文件最多 5 MB，最多 1000 个 SVG 几何元素，最多约 150000 个输入点。JSON 项目会校验格式、坐标、设置范围和颜色。
